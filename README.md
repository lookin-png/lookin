# LOOKIN

Статический сайт авторской студии Александра Лукина. Обычные HTML, CSS и JavaScript: установка пакетов и сборка не нужны.

## Файлы сайта

- `index.html` — содержание страницы, карточки портфолио и раздел основателя.
- `styles.css` — оформление и адаптация для разных экранов.
- `script.js` — переключение визуальных концепций, фильтры и создание брифа.
- `assets/` — изображения, которые используются на сайте.
- `.nojekyll` — публикация готовых файлов без обработки Jekyll.

Изображения хранятся локально. Шрифты Anton, Manrope и Oswald загружаются с Google Fonts; без интернета браузер использует запасные шрифты.

## Посмотреть локально

Откройте `index.html` в браузере. Или запустите в папке проекта, если установлен Python 3:

```sh
python3 -m http.server 8000
```

Затем откройте [локальный сайт](http://localhost:8000). Остановить сервер можно сочетанием `Ctrl+C` в терминале.

## Разместить на GitHub Pages

1. Создайте репозиторий на GitHub и загрузите файлы сайта с папкой `assets/`. Файл `index.html` должен быть в корне репозитория.
2. Откройте **Settings → Pages**.
3. В **Build and deployment → Source** выберите **Deploy from a branch**.
4. Выберите ветку с файлами, например **main**, папку **/(root)** и нажмите **Save**.
5. Дождитесь завершения публикации. Ссылка появится в разделе **Pages**; следующие изменения в выбранной ветке обновят сайт.

Для бесплатного размещения через GitHub Free используйте публичный репозиторий. Подробности — в [официальной инструкции GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site). При загрузке через браузер не добавляйте исходники из `output/` и большой исходный PNG портрета: `.gitignore` применяется только при работе через Git.

## Заменить содержание

Карточки портфолио пока содержат демонстрационные концепции. В `index.html` замените изображения, названия, описание, роль и категории на реальные проекты. Новые изображения положите в `assets/` и используйте относительные пути вида `assets/project.jpg`, чтобы ссылки работали и локально, и на GitHub Pages.

Для двух изображений первого экрана обновите пути в объекте `galleryAssets` в `script.js` и начальный `src` элемента `.lp-hero-image` в `index.html`. Выбор кадра запоминается только в текущем браузере. Начальный вариант — CHROME.

Контактный блок сейчас помогает составить бриф локально в браузере; он не отправляет заявку в студию. Перед запуском добавьте в `index.html` настоящий email или Telegram. Для автоматического приёма заявок потребуется отдельный сервис форм или сервер.

Папка `output/` и исходный `assets/alexander-lukin-portrait.png` сохранены локально, но исключены из Git. Рабочие JPEG-изображения в `assets/` нужно загрузить вместе с сайтом.
